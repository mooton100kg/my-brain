# Propofol
- Mechanism = GABA<sub>A</sub>
- Effect
	- CNS = ↓ O2 consumption, ↓ ICP
	- RS = RS depression, bronchodilation
	- Eye = ↓ IOP <span class='hl2'>(ใช้ได้ใน globe rupture / glaucoma)</span>
	- CVS = ↓ CO, vasodilation
	- ↓ N/V, pruritus
- S/E
	- Myoclonus
	- ปวดเวลาเดินยา อาจจะใช้ lidocaine นำก่อน
	- Propofol infusion syndrome (>4 mg/kg/h + >48 h)
		- Acute refractory bradycardia → asystole → **death**
		- Metabolic acidosis, rhabdomyolysis, hyperlipidemia

> [!info] Fospropofol
> เป็น prodrug ของ propofol ต้องถูก hydrolysis ที่ epithelial cell ก่อน ทำให้เจ็บตอนฉีดน้อยกว่า
# Benzodiazepine
- Option
	- Midazolam = ละลายน้ำในกรด
	- Diazepam
	- Lorazepam = not water soluble
- Effect
	- <span class='hl1'>Anterograde amnesia</span>
	- CNS = ↓ O2 consumption, ↓ ICP, anticonvulsant
	- RS = RS depression
	- CVS = <span class='hl2'>relatively stable hemodynamic</span>
	- Muscle relaxant
- Metabolism
	- ผ่านตับกลายเป็น active metabolite = midazolam, diazepam
	- ผ่านตับกลายเป็น inactive metabolite = lorazepam
- Flumazenil = <span class='hl3'>antidose </span>
	- Onset = 1-3 min
	- Duration = 1 hr
	- S/E = withdrawal syndrome
# Barbiturates (thiopental)
- Mechanism = GABA<sub>A</sub>
- C/I = acute intermittent porphyria
	- ยาจะกระตุ้นอาการให้กำเริบผ่าน Y-aminolevulinic acid synthetase
- Effect
	- CNS = ↓ O2 consumption, ↓ ICP, **anticonvalsant**
	- RS = double apnea 
	- Eye = ↓ IOP
	- CVS = ↓ CO, vasodilation, tachycardia

- ตกตะกอนใน acid / ringer lactate
- ถ้าฉีดเข้า intra-arterial 
	- จะตกผลืกเกิด vasoconstriction, thrombosis, necrosis
	- Tx
		- Vasodilation
			- Papaverine + lidocaine
			- Brachial plexus block
		- Heparin
		- Saline (artery)
# Ketamine
- Mechanism = NMDA antagonist
- Effect
	- CNS = dissociative anesthesia
	- RS = ↑ secretion, bronchodilation
# Etomidate
- ไม่ละลายน้ำ ต้องผสมกับ propylene glycol
- Effect
	- CNS = ↓ O2 consumption, ↓ ICP, <span class='hl2'>eleptogenic</span>
	- RS = น้อยเมื่อเทียบกับยาอื่น
	- CVS = <span class='hl1'>stable hemodynamic </span>
	- <span class='hl1'>Endocrine</span> = inhibit 11B-hydroxylase → cortisol & aldosterone production
-  S/E
	- Myoclonus
	- N/V, สะอึก
	- Thrombophlebitis
# Dexmedetomidine
- Mechanism = a2 agonist → อาการหลับจะปลุกให้ตื่นง่าย เเละกลับไปหลับได้อีก
- Effect
	- CNS = ↓ O2 consumption, ↔︎ ICP
	- RS = กดการหายใจคล้ายการหลับตามธรรมชาติ, ↓ secretion
	- CVS = ตอบสนองเเบบ biphasic
		- Early = ↑ BP, ↓ HR (peripheral a2 → vasoconstriction)
		- Late = ↓ BP, ↓ HR (ขึ้นเล็กน้อยจากตอนเเรก)
