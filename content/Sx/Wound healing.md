# Wound healing phase
![[image-29.png]]
1. Hemostasis = immediate
2. Inflammation = 72hr 
	- Neutrophil มาก่อนเเล้วตามด้วย macrophage
3. Proliferation = 3d - 3wk
	- Angiogenesis
	- Granulation tissue formation
	- Epithelialization
4. Remodeling = >3wk
	- Tensile strength
		- 1wk = 3%
		- 3wk = 30%
		- 3mo = 89%
	- Collagen type 3 เปลี่ยนเป็น 1

> [!tip] Wound
> - Acute > 4wk
> - Chronic > 4wk
