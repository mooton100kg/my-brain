# Normal voiding cycle
## Neural control
- Parasympathetic 
	- Location = S2-4
	- Nerve = pelvic
	- Muscle = detrusor muscle
- Sympathetic 
	- Location = T11-L2
	- Nerve = Hypogastric
	- Muscle = internal sphincter
- Somatic 
	- Location = S2-4
	- Nerve = pudendal 
	- Muscle = external sphincter
## Mechanism 
- Pelvic nerve รับความรู้สึกปวดฉี่ ส่งไปให้ PMC (pontine mictulation center)
- PMC ส่งไปถาม cerebral cortex ว่าตัดสินใจจะฉี่ไหม
- PMC สั่งให้ฉี่ทาง pelvic nerve
# Urinary retention
- Acute urinary retention = ยังรู้สึกปวดฉี่อยู่
- Chronic urinary retention = ไม่รู้สึกปวดฉี่เเล้ว
## Cause
1. Bladder hypocontractility
	- Neurogenic bladder 
	- Post radiation = detruxor muscle เกิด fibrosis
2. Bladder outlet obstruction
	- BPH, POP (pelvic organ prolapse)
	- Urethral stricture
	- Urethral stone
	- Post radition
	- 2nd chimosis จาก chronic inflammation in DM
	- CA penis
3. Transient UI = <span class='hl1'>DIAPPERS</span>
	- <span class='hl1'>D</span>elirium / dementia
	- <span class='hl1'>I</span>nfection = ตรวจ UA
	- <span class='hl1'>P</span>harmacological
		- Pseuoephedine
		- Anticholinergic drug
		- Muscle relaxant
	- <span class='hl1'>P</span>sycholoical = depression
	- <span class='hl1'>E</span>xcessive urine output
		1. น้ำ fill เข้า bladder เร็ว
		2. เกิด overdistent of bladder
		3. กลายเป็น acontractile bladder
	- <span class='hl1'>R</span>estrict mobility
	- <span class='hl1'>S</span>tool impaction = rectum dilate ไปอุด bladder neck

# BPH
## Location
- Transitional zone = M/C
- Central zone
- Peripheral zone = common in CA prostate

> [!tip] PSA
> ถ้าเป็น AUR อยู่ไม่สามารถเเปลผลได้

## Management
### Lifestyle change
- งด 4C = coffee coco carbonate citrus
- Double void
- เลี่ยง antihistamine / decongestant
###  Medical Tx
- Alpha1 antagonist 
	- Mechanism = relaxe muscle at bladder neck
	- Option
		- Doxazocin (cardura) 
		- Tamsulosin (harnal)
		- Alfuzosin (xatral)
	- S/E
		- Oethostatic hypotension 
		- Nasal congestion
		- Retrograde ejeculation
- 5 alpha reductase inhibitor
	- Mechanism = ↓ prostate size
	- Option
		- Finasteride (proscar)
		- Dutasteride (avodart)
	- S/E
		- Libido, ejeculation, erectile dysfuntion
- Antimuscarinic = ใช้ใน overactive bladder
- F/U 2wk → off foley
###  Sx Tx
- <span class='hl1'>Indication</span> #Elderly/imo 
	- Refractory urinary retension
	- Renal insufficiency
	- Recurrent UTI
	- Persitent hamaturia
	- Bladder calculi
	- Bladder diverticulum
	- Fail medication 
- Option
	- TURP = transurethral resection prostate
		- Complication = dilutional hyponatremia
			- Dizziness, headache, N/V, dyspnea
			- Pink frothy sputum
	- Enucleation
### How to choose Tx
1. IPSS
	- 0-7 (mild) = lifestyle modification
	- 8-19 (mod) = alpha blocker
	- ≥ 20 (severe) = combined med
2. Prostate size 30-40g <span class='hl3'>or</span> PSA ≥ 1.5 = combined med
### IPSS score
- FUN IS <span class="hl4">(H)</span>IS = ไม่มี hesitency
	- Frequncy
	- Urgency
	- Nocturia
	- Intermittency
	- Straining
	- Incomplete emptying
	- Weak stream
# Neurogenic bladder
## Cause
- Stroke = cerebral cortex / pons
- Spinal cord injury
- DM = peripheral nerve damage ทำให้เกิด acontractile bladder
- Post pelvic surgery
# Urine drainage
- Retain foley
	- Female no.14
	- Male no.16
- CBI = continuous bladder irrigation
	- ใช้ในกรณีมีเลือดออก ป้องกัน clot
- CIC = clean intermittent cath
- Retain suprapubic cystostomy = ดีในผู้ชาย เพราะมี gland ใน urethra เยอะ
## Difficult cath
1. Push xylocaine jelly
2. Change Cath size
	- BPH = larger
	- Stricture = smaller
3. Try feeding tube no.6-8
4. Consult uro = cystoscopy
## CIC
- 4-6 times/d
- Complication
	- UTI
	- False tract
	- Urethritis
	- Bleeding 
	- Urethral stricture
