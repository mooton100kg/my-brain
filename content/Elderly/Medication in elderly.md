# Adverse drug reaction
- Type A = dose related
- Type B = idiosyncratic / allergic
- Type C = duration related
- Type D = delayed reaction

> [!tip] Anti-cholinergic effect
> - 1st gen anti-histamine
> - BZD
> - TCA
