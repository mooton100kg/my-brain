# Ventilation
- Position = tripple airway maneuver + รองหมอนที่ไหล่
	- Head tilt, chin lift
	- Jaw thrust
	- Open mouth
- Option
	- Adjunct airway
		- Nasopharyngeal airway = tip of nose to ear lobe
		- Oropharyngeal airway = middle of incisor to angle of mandible
	- Supraglottic airway
		- LMA
	- Definite airway <span class="hl4">= เเยกทางเดินหายใจออกจากทางเดินอาหาร</span>
		- ETT
		- Tracheostomy tube
## Face mask ventilation
- Definition = positive pressure ventilation using bag-valve-mask unit
- Indication
	- Rescue ventilation
	- Bridge to intubation
- อุปกรณ์
	- Mask = no 3-4
	- Reservoir bag
		- Self-inflating
		- Collapsible
	- Oxygen
- <span class='hl1'>Idea</span> = acceptable gas exchange without gastric inflation
	- Slow inspiratory flow = Ti 1sec
	- Small TV = just chest move
	- High RR
	- PIP < 20
	- Full expiration
### Difficult face mask ventilation <span class='hl1'>= MOANS</span>
- <span class="hl1">M</span>ask seal
- <span class='hl1'>O</span>bstruction / obesity
- <span class='hl1'>A</span>ge > 55
- <span class='hl1'>N</span>o teeth
- <span class='hl1'>S</span>tiff lung / OSA
# Intubation
- Position
	- Sniffing + รองหมอนที่หัว
		- Flex neck
		- Extend atlanto-occipital joint
	- <span class="hl4">ยกเว้นอ้วนมากใช้ ramp positive</span>
- Indication = <span class='hl1'>4P</span>
	- <span class='hl1'>P</span>ositive pressure ventilation
	- <span class='hl1'>P</span>atent airway
	- <span class='hl1'>P</span>rotect airway
	- <span class='hl1'>P</span>ulmonary toilet
- อุปกรณ์
	- ETT
		- Size
			- Male = 7.5-8
			- Female = 7-7.5
	- Laryngoscope
		- Adult asian = MacIntosh no.3
		- Children = Miller
	- Suction = เบอร์ ETT x 2
- Preoxygenation = ventilation with 100% O2 for 3min
