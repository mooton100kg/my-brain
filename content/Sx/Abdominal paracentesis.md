# Indication
- Diagnosis
- Therapeutic
# Contraindication
- Absolute
	- DIC
- Relative
	- Pregnancy
	- Distent urinary bladder 
	- Distend bowel
	- Abdominal wall cellulitis
	- Severe thrombocytopenia < 20,000 <span class='hl3'>or</span> PT > 21sec
# Procedure
1. หา location = ช่องท้องส่วนล่าง 
	- จาก ASIS 2 fingerไปทาง medial + 3 finger ไปทาง superior
	- ± Shifting dullness
	- ± U/S
2. ใส่ถุงมือ sterile 
3. เตรียมยาชา lidocaine 3-5 ml
4. paint ปูผ้า 
5. ฉีดยาชาชั้น intradermal เเล้วเเทงเข้าด้านในช่องท้องพร้อมกับ negative ไว้ เเล้วฉีดยาชาตอนมีน้ำเข้ามา ถ้าลมเข้าเเสดงว่าเข้าลำไส้ให้ดึงเข็มออก
6. ใช้ Tooth forceps เช็ค
7. ใช้เข็ม Jelco no. 18/20 เจาะ 
	- Angular technique = วางเข็ม 45º กับ skin 
		![[Pasted image 20251103222637.png|200]]
	- Z track technique = ใช้มือดึงผิวลงมา 2 cm เเล้วใช้เข็มเเทงลงไปตรงๆ
		![[Pasted image 20251103222822.png|200]] <br>
	- Diagnosis = เอาน้ำ 20-30 ml
	- Therapeutic = ใส่ 3 way ต่อกับ extension ระบายน้ำเข้าขวด ~2L ถ้าเยอะกว่านั้นต้องให้ albumin
8. ใช้ gauze ปิดเเผล
9. Monitor V/S = HR, BP
